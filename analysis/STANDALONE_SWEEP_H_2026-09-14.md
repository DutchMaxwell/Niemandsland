## The three rows I would fix first
1. Self-Destruct (DIVERGES) — the core implements only the death-half (unit.rs:2011-2019 -> sim.rs:3541-3556) while the table also runs the survival half (main.gd:17216-17240): surviving detonators must be killed post-melee and pay X hits to the enemy. A player in a core-driven fight keeps an unkillable-ish Self-Destruct survivor alive and never suffers the detonation — a swing the table rules explicitly demand. Fix: port `_solo_self_destruct_post_melee` to the tray melee epilogue next to the Deathstrike death-half.
2. Steadfast (DIVERGES) — the core free-clears Shaken on steadfast_active at every round refresh (rollout.rs:549-555), but the die-roll recovery wave's name list (unit.rs:1365) omits Steadfast while the table rolls its printed 4+ (main.gd:10707-10720, recover_target=4). Core-driven games make Steadfast strictly better than Battleborn for free; the printed rule is a 4+ roll. Fix: include "Steadfast" in battleborn_recover_target_of so the playout rolls its stamped target, keeping the planner's imagined refresh untouched.
3. Vinci Tech Boost (DIVERGES) — the core treats pick_one=false as BOTH arms (unit.rs:5359-5393, dice.rs:910-913: +1 to hit and AP+1 past 9"), while the table's chooser always picks exactly one (main.gd:3273 versatile_best_mode) and never reads pick_one. One side of the port fights with double the boost. Fix: either honour pick_one=false in the table chooser or gate the core's versatile_both read — one truth for both seats.
