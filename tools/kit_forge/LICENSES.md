# Licences — ruin-town dressing kit

## Meshes (`kit/*.glb`)

Own work, generated by the scripts in this directory (`dress_kit.py`, `kit_build.py` and the
batch builders); no third-party geometry. Licence: **CC-BY-SA-4.0** (the project's asset licence).
No embedded images: every primitive carries only a named placeholder material.

## Texture sets

All sets come from [Poly Haven](https://polyhaven.com/license), licence **CC0-1.0**. The baked
`.ctex` files are delivered at runtime like the project's other texture sets; they are not stored
in git. The manifest (`assets/ruintown_dress.json`, `sets` block) records each source and the
content-addressed `.ctex` file names.
